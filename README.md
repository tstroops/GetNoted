# Get Noted

## Thomas S; Nick S; Josh K; John A

## Software Description
A note-taking app where you can take class notes and store them in notebooks. 

## Architecture
Kotlin
Android Studio
SQL
Supabase Postgres and Auth

* [x] creates, edits, deletes, saves, and loads notes and notebooks

## Reflections

Thomas Stroops: The cloud database was by far and away the biggest hangup. 
However, the fact that we taught ourselves Android Studio and Supabase 
and used them to build an app in 300 working hours is very impressive. 
I proved to myself in this class that I can teach myself things 
and then use that knowledge to build something impressive.

Josh Kotter: Before starting this assignment, none of us knew how to work
the Kotlin language or the Supabase system, so learning those was a big
step towards getting our app to work at all. Improvements are mostly on
the app functions we didn't have time to fully fleshed out, like the delete
notes button and some of the UI. We also had a lot of features we wanted to add
that we didn't have time for, like AI writing-to-text integrating and functionality 
on multiple operating systems.
